EnvHarness: Awakening Static Worlds for Agent Learning
↑217
Authors: Chengsong Huang, Chen-Yu Lee
Affiliation: Washington University in St. Louis

↑175

Affiliation: National University of Singapore, Xidian University

Co-RL: Unsupervised Reasoning Emerges from Diverse Cohort in Multi-agent RL
↑77
Authors: Yunhao Yang, Yijiang Li
Affiliation: Johns Hopkins University
提出 Co-RL，用多个参数解耦模型组成多样化 cohort，通过彼此生成的 reward 信号进行无监督 RL，从而降低单模型 self-rewarding 的偏差强化和训练塌缩。模型家族、规模和样本改写带来的多样性可减少相关错误，在文本和多模态 reasoning 基准上无标注也能接近或超过监督方法。

Authors: Zhi Zheng, Wee Sun Lee
Affiliation: National University of Singapore
主张用 evolution strategies 替代传统 RL 来微调长程 LLM agents。ES 只需推理级显存、黑盒反馈接口，并可与 prompt-space evolution、skill 优化和 test-time compute 组合，更适合分支多、奖励稀疏的 agentic 任务。论文展示 Agentic ESOpt 能以较低 GPU 要求优化长 horizon 行为。
Demystifying Agent Skills: Why They Work-Until They Don't
↑64
Authors: Zhiyuan Jiang, Yijiang Li
Affiliation: Princeton University
通过控制实验和轨迹对比解释 agent skills 何时有效、为何有效、何时失败。研究发现 skill 主要充当 procedural anchor，而非注入缺失事实；相比 workflow memory 有稳定收益，但大 skill pool 中检索精度急剧下降。失败常来自脆弱假设、不兼容上下文或缺乏适配。

AlphaXiv

Proteus: Incremental Memory Activation for Long-Context Sequence Modeling
AlphaXiv
Authors: Reza Bayat, Aaron Courville
Affiliation: Mila, Université de Montréal
针对长上下文记忆模型一开始就暴露完整静态 memory 导致早期 token 污染容量的问题，提出 Proteus：随上下文增长逐步激活更多 memory block。早期瓶颈迫使有效压缩，后期新容量减少覆盖和干扰。该机制可无额外成本接入 SWLA、Comba、Titans、Hope-Attention 等模型并稳定提升长程任务。

Recirculation
AlphaXiv
Authors: Michael C. Mozer, Rosanne Liu
Affiliation: Google DeepMind
提出 recirculation，一种训练无关的推理时架构增强：在 prefill 阶段引入特定 recurrence，使现有 foundation model 像 dynamical system 一样跟踪 belief state。该方法生成阶段几乎不增延迟，在 Gemma3 系列上降低困惑度并提升 GSM8k 等任务准确率，区别于 chain-of-thought 和昂贵 recurrent transformer 训练。
Depth Anything V4: Dynamic 4D Scene Reconstruction via Riemannian Flow Matching on 4D Gaussian Splatting
AlphaXiv
Authors: Jiaming Fan, Chenbin Zhang
Affiliation: College of Artificial Intelligence, Nanjing University of Posts and Telecommunications
提出 Depth Anything V4，用 Riemannian Flow Matching 建模 4D Gaussian Splatting 的尺度、旋转、透明度等非欧参数，保证中间状态有效。受控实验隔离出 RFM 相比同设置 MLP 基线带来 +0.044 F-score，并在动态重建与新视角合成上优于既有 Depth Anything 和逐场景 4D-GS。
4DAnyone: Create Anyone in 4D from a Casual Monocular Video
AlphaXiv
Authors: Yudong Jin, Xiaowei Zhou, Yinghao Xu
Affiliation: State Key Lab of CAD&CG, Zhejiang University, Robbyant
提出 4DAnyone，用随手拍单目视频重建动态人体 4DGS。方法先用稀疏 3D 骨架条件生成多视角一致视频，再通过 Reference Context Packing 压缩不断增长的参考视角、Target Context Routing 在分组去噪间交换上下文。实验在 DNA-Rendering 和 DyMVHumans 上提升新视角视频质量与下游 4DGS 重建，并展示野外视频泛化。

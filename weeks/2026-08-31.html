Repo-To-Skill: Distilling GitHub Repositories Into AI4AI Skills
↑347
Authors: Jianlyu Chen, Zheng Liu
Affiliation: Beijing Academy of Artificial Intelligence, University of Science and Technology of China
提出 DisCo，把 GitHub repo 里的 operational knowledge 蒸馏成可复用、可验证的 AI4AI skills，并构建 AREX-Skill Library（1000 个 ML repo、5000+ skills）。在固定 GPT-5.5 backbone、harness 与预算下，加入 skills 的研究 agent 在 MLE-bench、PaperBench、FrontierCS、PassNet 上均明显优于无 skill 版本。
StudentSim: Training LLM-based Student Simulators
↑303
Authors: Ke Yang, Jianfeng Gao
Affiliation: Microsoft Research, University of Illinois Urbana-Champaign
提出 StudentSim，用“群体训练 + 个体学生专门化”把稀疏学习记录转成可个性化的学生模拟器，同时评估行为保真度与接受指导后的响应性。StudentSimEval 覆盖棋类、二语写作和数学 60 名学生；结果显示其在三域均优于 GPT-5.4，并可作为 tutor RL 的奖励信号提升个性化教学。
Qwen-Drive-1.0: An Initial Step towards a Vision-Language Foundation Model for Autonomous Driving
↑301
Authors: Xin Zhou, Xiang Bai
Affiliation: Huazhong University of Science and Technology
介绍 Qwen-Drive-1.0：在不改变预训练 VLM 架构的前提下，用外接 BEV 感知头和 Planning Expert 统一 3D 感知、驾驶 VQA 与运动规划。分阶段训练结合驾驶监督与通用视觉语言数据，使模型获得驾驶能力并尽量保留通用 VLM 能力，在多类开环、伪闭环和闭环评测中表现有竞争力。
EarlyEval: Cheaper Agent Evaluation via Early Outcome Prediction
↑104
Authors: Yuling Shi, Xiaodong Gu
Affiliation: Shanghai Jiao Tong University, Shanghai, China
提出 EarlyEval，通过 early outcome prediction 在单个 agent 任务中提前判断成功/失败，而不是只缩小 benchmark。它用 LightGBM 分类器读取轨迹行为、文本和 reference-solution 特征，一旦置信度达阈值就停止；在 SWE-bench Verified、TerminalBench、Toolathlon 上节省 13%–26% steps、最多 44.1% input tokens，且成功率扰动很小。
DreamX-Creator: Democratizing Native Audio-Video Generation at 2K Resolution
↑84
Authors: Jiashu Zhu, Xiangxiang Chu
Affiliation: DreamX Team, Alibaba Group
介绍 DreamX-Creator 1.0：以 7B 生成器原生联合生成音频与视频，通过 Gated Cross-Modal Attention、统一音视频数据系统、渐进联合训练和多模态反馈 RL 提升同步性与质量，并用 1-step 2K Refiner 支持高分辨率输出。
HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?
↑83
Authors: Yuhao Wu, Wenxuan Zhang
Affiliation: ByteDance Seed
提出 HarnessDev，把评测对象从 agent 输出转为可运行 harness infrastructure，考察 LLM 从最小 seed 创建 harness 并基于反馈迭代演化的能力。结果显示自动生成 harness 在代码、搜索、研究任务上仍落后人工参考，在写作和 ML 实验中可接近或超过参考；演化收益不稳定且跨执行模型迁移有限。
LoopArena: Benchmarking Models as Runtime Controllers for Loop Engineering
↑78
Authors: Yi Wang, Xiangxiang Chu
Affiliation: DreamX Team, Alibaba Group, Beijing University of Posts and Telecommunications
提出 LoopArena，把模型作为 Controller，基于运行摘要指挥固定 Worker coding agent 下一步做什么或是否停止。基准覆盖单步决策、任务片段和完整长程任务；最佳全任务严格成功率仅 24.69%，Type II 排名与全任务高度一致并平均节省 64.4% 推理成本。
Aspire: Can Models Self-Evolve from Vague Goals?
↑72
Authors: Yuhao Wu, Ge Zhang
Affiliation: ByteDance Seed
提出 ASPIRE，用“模糊目标”测试模型自我演化：只给自然语言能力目标，隐藏下游评测，要求 agent 自行选择数据、训练/验证信号与评估时机。520 个专家题显示，当前 agent 能完成训练和 harness 编辑循环，但权重增益稀疏不稳，常因数据错配和狭窄 self-eval 无法泛化。
SMELT: Scaling Laws for Compute-Matched MoE Looped Transformers
↑64
Authors: Shaowen Wang, Jian Li
Affiliation: Tsinghua University
提出 SMELT，在 MoE Transformer 中让中间一半层循环执行两次，并同时匹配 per-token FLOPs、总参数与 KV cache。作者将方法扩展到最高 54B 非 embedding 参数并拟合缩放律，显示在 compute-optimal frontier 可节省 6.8%–18.0% 训练 FLOPs；收益在代码、长样本和更多 in-context 示例下更明显。
It Takes Two to Match: Co-Evolving Generative Retriever with Reinforcement Learning
↑61
Authors: Runpeng Dai, Ciya Liao
Affiliation: University of North Carolina at Chapel Hill, Apple
提出 CoGR，让 LLM 在 query 端和 item 端直接生成可倒排索引匹配的关键词表示，而非只做 query expansion。方法先用 SFT 对齐关键词空间，再用 GRPO 交替优化两端生成器；在内部 APP Marketplace 和 WANDS 上超过稀疏、稠密、生成式基线，F1 较最强基线提升 10.9% 和 36.1%。
Normalized Low-Rank Adaptation
AlphaXiv
Authors: Jiale Kang, Weiyang Liu
Affiliation: Yuanshi Intelligence, The Chinese University of Hong Kong
提出 NoRA：在 LoRA 训练中归一化 down-projection 矩阵，并指出仅初始化时归一化也能改善标准 LoRA。方法不增加参数和推理开销，在预训练、监督微调和强化学习中提升收敛速度、稳定性与性能，并缓解灾难性遗忘。
Does On-Policy Distillation Really Distill? From Noisy Teacher to Self-Improvement
AlphaXiv
Authors: Yi Ding, Ruqi Zhang
Affiliation: Department of Computer Science, Purdue University, USA
重新审视 on-policy distillation：教师给学生生成轨迹打分时噪声很大，但学生改进主要来自抑制低概率 token，而非真实蒸馏。基于此提出无需教师的 OPSA，用熵自适应负优势重分配概率，在 AIME 等数学基准上超过 OPD。

AlphaXiv
Authors: Junchao Huang, Li Jiang
Affiliation: CUHK-SZ, SLAI

Harness-of-Harness: Multi-Day Autonomous Software Development with Continual Improvement
AlphaXiv
Authors: Haoyang Yan, Shuyue Hu
Affiliation: Shanghai Artificial Intelligence Laboratory
提出 Harness-of-Harness (HoH)，在已有 coding-agent harness 外组织 planning-coding-testing 循环，让 agent 持续修复并增长能力。它用小步可验证增量、独立评测和版本化历史支撑多轮改进，在 GameCraft-Bench、FrontierSWE、ProgramBench 上平均相对提升 52.25%，并多日迭代出可玩的 FPS 游戏。

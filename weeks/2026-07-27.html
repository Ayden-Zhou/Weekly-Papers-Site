Metis: Memory Foundation Model
↑196
Authors: Zeyu Zhang, Xu Chen, Zhiyu Li
Affiliation: MemTensor (Shanghai) Technology Co., Ltd., Renmin University of China
针对 agent memory 仍多依赖外部模块的问题，提出 memory foundation model 概念，并实现原型 Metis：在模型内部维护可演化的 native memory state，通过 memory attention 存取历史信息。Metis 用记忆专项数据和多目标中训练学习存储/利用流程，推理时权重冻结、仅前向即可更新记忆，在多项实验中展示原生记忆能力。
Qwen-UI-Agent Technical Report: Toward Next-Generation Real-World Centric Foundation GUI Agents
↑177
Authors: Hanzhang Zhou, Steven Hoi
Affiliation: Alibaba Token Hub, Alibaba Group
提出面向真实设备的基础 GUI agent Qwen-UI-Agent，覆盖移动端、computer use、Web 和 DeepSearch。系统结合沙盒与大规模真实移动设备环境，统一 GUI 与 CLI 混合动作、单轮批量动作、数据飞轮和长轨迹在线 RL，并用轻量 harness 支持主动服务与跨平台状态化工作流，在移动端基准达到 SOTA，同时在桌面和浏览器任务上保持强竞争力。
PhiZero: A World Model Built Around Physical Language
↑147
Authors: Shuyao Shang, Lue Fan, Zhaoxiang Zhang
Affiliation: NLPR, Institute of Automation, Chinese Academy of Sciences (CASIA)
提出 PhiZero，把物理世界模型建立在 physical language 这种离散状态转移表示上，而不是直接在像素空间隐式预测未来视频。模型先 reason：生成未来演化的 physical-language 序列，再 render：把转移渲染为视频；这种 reason-then-render 范式提升物理一致性，并展示了交互式世界建模、细粒度动作条件模拟和零样本运动迁移潜力。
AskChem: Claim-Centered Infrastructure for Chemistry Literature Synthesis
↑128
Authors: Bing Yan, Kyunghyun Cho
Affiliation: New York University
针对化学文献综合需要跨论文定位、验证和组织具体发现的问题，提出 AskChem，将检索单元从论文改为带 provenance 的 typed claim。系统把论文转成带 DOI 与证据位置的原子 claims，并提供分面 taxonomy、evidence graph 与 living taxonomy；当前索引 14.7 万篇论文的 240 万 claims，在 AskChem-Bench 上提升 DOI 可解析率和引用密度。
TurboVLA: Real-Time Vision-Language-Action Model at 32 Hz on an RTX 4090 with <1 GB VRAM
↑114
Authors: Hengyi Xie, Han Ding
Affiliation: Huazhong University of Science and Technology
针对以 LLM 为中心的 VLA 推理开销高、难以实时部署的问题，提出 TurboVLA，将传统 V→L→A 改为直接的 V+L→A：独立编码视觉和指令，用轻量双向交互与紧凑解码器预测连续动作块。在 LIBERO 上以 0.2B 参数达到 97.7% 成功率，并在 RTX 4090 上实现 31.2 ms 延迟、0.9 GB 显存和 32 Hz 控制。

CoRT: Counterfactual Replay for Token-Level Rubric-Guided Policy Optimization
↑65
Authors: Bo-Wen Zhang, Lan-Zhe Guo
Affiliation: State Key Laboratory of Novel Software Technology, Nanjing University, School of Intelligence Science and Technology, Nanjing University, ByteDance
针对 rubric-based RL 在 GRPO 中把结构化评审压成 response-level 标量、再均匀广播到所有 token 的 credit assignment 问题，提出 CoRT。它对同一采样回答分别在含 rubric 和去 rubric 提示下重放打分，用 tokenwise likelihood contrast 生成有界权重，重分配 GRPO advantage；无需额外 token scorer，平均提升 4.4 个百分点。
From Proprietary to Open-Source: Bridging the Distribution Gap via Multi-Agent Protocol Distillation in Agentic Search
↑63
Authors: Junlin Liu, Chenxi Zhou
Affiliation: Beijing Institute of Technology
针对 agentic search 中 RL 奖励稀疏、闭源教师 logits 不可得且自然语言轨迹蒸馏易带来风格漂移的问题，提出 MAPD：先由离线多智能体系统把搜索轨迹转成结构化 JSON protocol，再用特权分支提供密集蒸馏信号并结合 RL 训练。七个 QA 基准上显著优于对比蒸馏和 RL 方法。

↑63

↑61
Authors: Haodong Li, Pheng-Ann Heng
Affiliation: The Chinese University of Hong Kong
针对文生视频难以从压缩文本提示中隐式推断完整物理演化的问题，提出 VideoCoCo，将可执行 Blender 代码作为 process-level chain of thought。coding agent 先生成描述场景和时间演化的程序，由模拟引擎产出确定性草稿，再由视频生成引擎做 photorealistic 编辑；配套 VideoCoCo-3K 训练数据，在 PhyGenBench 和 VBench-2.0 上提升物理一致性指标。
Expanding Flow Maps
AlphaXiv
Authors: Sophia Tang, Pranam Chatterjee
Affiliation: University of Pennsylvania
针对现有 flow 生成模型通常固定维度或固定序列长度的限制，论文提出 Expanding Generative Flows 与 Expanding Flow Maps：先用条件噪声扩展状态空间，再通过 transport map 推进去噪，从而在少步生成中同时扩展与生成。框架覆盖连续空间和离散 simplex，可用于可变大小图与可变长度序列生成，让输出规模本身成为可学习、可控的自由度。

AlphaXiv

Wonder: Video World Model Done Better
AlphaXiv
Authors: Jiacong Xu, Yiqun Mei
Affiliation: Adobe Research
提出 Wonder，一个实时、相机可控的视频世界模型，可从图像或条件视频生成可交互探索的长时程世界。方法结合 dense coordinate field 相机条件、高效 sparse-attention 记忆检索和改进 self-forcing 蒸馏，使模型在 16 FPS 下生成分钟级视频，同时保持几何、外观、动态和长程记忆一致，并支持对既有动态场景实时重拍。

SkillOpt: Executive Strategy for Self-Evolving Agent Skills
Authors: Yifan Yang, Xue Yang
Affiliation: Microsoft
提出 SkillOpt，把 agent skill 当作冻结模型的外部可训练状态，用优化器模型根据轨迹生成受限 add/delete/replace 文本编辑，并通过 held-out 验证门只接受提升性能的版本。实验覆盖六类基准、七个目标模型和三种执行 harness，显示优化后的技能可显著提升准确率，并能跨模型、跨 harness 迁移，且部署时不增加推理调用。
Lens: Rethinking Training Efficiency for Foundational Text-to-Image Models
Authors: Dong Chen
Affiliation: Microsoft
提出 3.8B 参数文生图模型 Lens，在显著较低训练算力下达到或超过更大模型。核心做法是提高每个训练 batch 的信息密度：使用 800M 密集 caption 数据、多分辨率和多宽高比 batch、语义 VAE 与强文本编码器加速收敛；再结合 RL、reasoner prompt search 和蒸馏支持高分辨率、多语言与 4-step 快速生成。
Rethinking Cross-Layer Information Routing in Diffusion Transformers
Authors: Chao Xu, Shao-Qun Zhang
Affiliation: Alibaba Group
系统分析 DiT 残差流在深度和去噪时间上的信息路由问题，指出幅值膨胀、梯度衰减和层间冗余。论文提出 Diffusion-Adaptive Routing，用可学习、随 timestep 变化的非增量聚合替代传统残差加法，并可与 REPA 等方法叠加；在 ImageNet 256 上提升 SiT-XL/2 的 FID，并以少得多的迭代达到基线质量。
Advancing Mathematics Research with AI-Driven Formal Proof Search
Authors: George Tsoukalas, Pushmeet Kohli, Swarat Chaudhuri
Affiliation: Google DeepMind
评估 LLM 加 Lean 形式化证明搜索解决开放数学问题的能力。AlphaProof Nexus 让多个子 agent 用 LLM 生成和修改 Lean 证明，并由编译器验证；完整 agent 还加入进化式协调和 AlphaProof 工具。系统自主解决 9/353 个 Erdős 问题、证明 44/492 个 OEIS 猜想，并在多个研究方向辅助发现证明或改进界限，展示形式化验证能把 LLM 推向研究级数学。
DVAO: Dynamic Variance-adaptive Advantage Optimization for Multi-reward Reinforcement Learning
Authors: Guochao Jiang
Affiliation: Alibaba Cloud Computing
针对多奖励 GRPO 中固定奖励合并易导致优势幅度爆炸、目标隔离和训练不稳的问题，提出 DVAO：按 rollout 组内各目标奖励方差动态加权，强化有效学习信号并抑制噪声。论文证明其能约束优势幅度并形成跨目标正则，在数学推理和工具使用任务上取得更优 Pareto 前沿和稳定性。
PiD: Fast and High-Resolution Latent Decoding with Pixel Diffusion
Authors: Yifan Lu, Xuanchi Ren
Affiliation: NVIDIA
提出 PiD，把潜变量解码重写为条件像素扩散，直接从 VAE 或语义 latent 生成 4x/8x 高分辨率图像，合并传统解码和超分阶段。通过 sigma-aware latent adapter 与 DMD2 蒸馏，PiD 可用 4 步完成 2K/4K 解码，在延迟、显存和视觉细节上优于级联超分流程。
LocateAnything: Fast and High-Quality Vision-Language Grounding with Parallel Box Decoding
Authors: Shihao Wang, Zhiding Yu
Affiliation: The Hong Kong Polytechnic University, NVIDIA
提出 LocateAnything，用 Parallel Box Decoding 将框和点等几何单元一次性并行解码，缓解逐 token 坐标生成带来的几何不一致和推理瓶颈。论文还构建超过 1.38 亿样本的 LocateAnything-Data，在多类 grounding 与 detection 基准上同时提升高 IoU 定位质量和解码吞吐。
Language Models Need Sleep
Authors: Sangyun Lee, Giulia Fanti
Affiliation: Carnegie Mellon University
探索类似“睡眠”的离线巩固机制：模型周期性把近期上下文通过多轮离线 recurrence 写入 SSM fast weights，再清空 KV cache。这样把额外计算移到 sleep 阶段，保持在线预测延迟，并在细胞自动机、多跳检索和数学推理任务上随 sleep 时长增加获得更强深层推理能力。
The MiniMax-M2 Series: Mini Activations Unleashing Max Real-World Intelligence
Authors: MiniMax, Ziyue Ge
Affiliation: MiniMax
介绍 MiniMax-M2 系列 MoE 语言模型，旗舰 M2 总参数 229.9B、每 token 激活 9.8B，面向 agentic coding 与复杂办公/搜索任务优化。核心包括可验证轨迹数据管线、agent-native RL 系统 Forge，以及 M2.7 的自调试与脚手架修改能力，使较小激活量在多项真实 agent 基准上接近前沿闭源模型。
Gamma-World: Generative Multi-Agent World Modeling Beyond Two Players
Authors: Fangfu Liu, Xuanchi Ren
Affiliation: Unknown
提出面向交互式仿真的多智能体生成世界模型 Gamma-World，解决单智能体视频世界模型难以扩展到多玩家、多机器人等共享环境的问题。方法用 Simplex Rotary Agent Encoding 保持智能体身份的可控性与置换对称性，并用 Sparse Hub Attention 将跨智能体注意力从二次复杂度降为线性；再通过因果学生模型和 KV cache 实现 24 FPS 实时 rollout。实验显示其在视频质量、动作可控性和跨智能体一致性上优于 slot-based 与 dense-attention 基线，并能从两玩家泛化到四玩家。
AgentDoG 1.5: A Lightweight and Scalable Alignment Framework for AI Agent Safety and Security
Authors: Dongrui Liu, Xia Hu
Affiliation: Unknown
面向开放世界 AI agent 的安全风险，论文更新 Codex/OpenClaw 等执行场景的风险分类，并用 taxonomy-guided 数据引擎与 influence-function purification 以约 1k 样本训练 0.8B-8B AgentDoG 1.5；它还能作为高效 SFT/RL 环境和在线 guardrail，在复杂交互式 agent 场景达到领先表现并降低部署开销。
When Does LeJEPA Learn a World Model?
Authors: David Klindt, Randall Balestriero
Affiliation: Unknown
从理论上说明 LeJEPA 何时能学到 world model：在潜变量满足平稳加性噪声转移时，alignment 加高斯正则可线性恢复真实潜变量；论文证明高斯分布是该保证成立的唯一情形，并给出近似可辨识性、最优潜空间规划结果和从低维到机器人控制的实验验证。
Qwen-VLA: Unifying Vision-Language-Action Modeling across Tasks, Environments, and Robot Embodiments
Authors: Qiuyue Wang, Xionghui Chen
Affiliation: Unknown
提出 Qwen-VLA，将 Qwen 的视觉语言建模扩展到连续动作和轨迹生成，用统一 VLA 模型覆盖操作、导航与轨迹预测。方法结合 DiT 动作解码器、大规模混合预训练和 embodiment-aware prompt，在多类机器人与环境中实现跨任务泛化，并在 LIBERO、RoboTwin、R2R/RxR 及真实 ALOHA 等基准上取得强表现。

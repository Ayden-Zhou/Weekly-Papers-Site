From Scale to Speed: Adaptive Test-Time Scaling for Image Editing
Authors: Xiangyan Qu, Gaopeng Gou
Affiliation: Institute of Information Engineering, Chinese Academy of Sciences, School of Cyber Security, University of Chinese Academy of Sciences
论文针对图像编辑中的测试时扩展效率低与冗余采样问题，提出 ADE-CoT 自适应框架：按编辑难度动态分配采样预算、用区域定位与描述一致性做早期筛选、并在达到意图对齐时深度优先提前停止。在 Step1X-Edit、BAGEL、FLUX.1 Kontext 上实现更优性能-效率折中，并较 Best-of-N 获得超过 2 倍加速。
OmniLottie: Generating Vector Animations via Parameterized Lottie Tokens
Authors: Yiying Yang, Gang Yu
Affiliation: Fudan University, StepFun
该工作面向 Lottie 向量动画生成，设计参数化 Lottie tokenizer，把原始 JSON 转成形状、运动函数与控制参数序列，并在预训练视觉语言模型上实现多模态自回归生成。配合 200 万规模的 MMLottie-2M 数据集，模型可统一支持 text-to-Lottie、text-image-to-Lottie 与 video-to-Lottie，提升语义对齐和动画质量。
CUDA Agent: Large-Scale Agentic RL for High-Performance CUDA Kernel Generation
Authors: Weinan Dai, Hao Zhou
Affiliation: ByteDance Seed, Institute for AI Industry Research (AIR), Tsinghua University, SIA-Lab of Tsinghua AIR and ByteDance Seed
CUDA Agent 通过大规模 agentic 强化学习提升 CUDA 内核自动优化能力，核心包括可扩展数据合成、带自动验证与性能分析的技能增强开发环境，以及稳定训练的 RL 技术。方法在 KernelBench 三个难度上相对 torch.compile 分别实现 100%、100%、92% 更快率，在最难设置上也显著超过多种强专有模型。
Utonia: Toward One Encoder for All Point Clouds
Authors: Yujia Zhang, Hengshuang Zhao
Affiliation: The University of Hong Kong
论文提出统一的自监督点云编码器 Utonia，在遥感、自动驾驶 LiDAR、室内重建、CAD 与视频重建点云等多域联合训练同一 Point Transformer。结果显示跨域迁移显著增强，并出现联合训练才有的表示能力；其特征还能提升机器人操作中的 VLA 策略与视觉语言模型的空间推理表现，朝 3D 基础模型迈进一步。
Understanding LoRA as Knowledge Memory: An Empirical Analysis
Authors: Seungju Back, Sungjin Ahn
Affiliation: KAIST
这项工作把 LoRA 视作可插拔的参数化知识记忆，而非仅是任务微调工具，并系统评估其“存得下、取得出、可组合、可扩展”的边界。实验覆盖容量、知识内化、多模块扩展与长上下文推理，结论是 LoRA 可作为 RAG/ICL 的互补记忆轴，但在配置不当时会出现明显失效，需要按容量与组合策略进行工程化设计。
Beyond Language Modeling: An Exploration of Multimodal Pretraining
Authors: Shengbang Tong, Luke Zettlemoyer
Affiliation: FAIR, Meta, New York University
论文通过从零开始的受控实验系统研究原生多模态预训练，采用 Transfusion 框架将语言 next-token 训练与视觉扩散训练统一。作者提出四点关键发现：RAE 视觉表征最均衡；视觉与语言数据联合训练有协同增益；统一训练可自然涌现世界建模能力；MoE 能更高效扩展并形成模态专门化。IsoFLOP 分析还表明视觉比语言更“吃数据”，MoE 有助于缓解该扩展不对称。
Think Deep, Not Just Long: Measuring LLM Reasoning Effort via Deep-Thinking Tokens
Authors: Wei-Lin Chen, Yu Meng
Affiliation: Unknown
论文指出 CoT 长度并不可靠代表推理质量，过长生成可能只是过度思考。作者提出 deep-thinking tokens，用模型深层预测发生显著修正的位置衡量真实推理努力；该比例在数学和科学基准上与正确率更稳定相关，并支持 Think@n 早期筛掉低潜力样本以降低推理成本。
Codified Context: Infrastructure for AI Agents in a Complex Codebase
Authors: Aristidis Vasilopoulos
Affiliation: Unknown
面向大型代码库中 agent 缺少持久项目记忆的问题，提出 codified context 基础设施。系统把项目约定、架构知识和常见错误组织成可维护上下文，并在 10.8 万行 C# 分布式系统构建过程中验证，目标是让多 session、多 agent 开发保持一致性、减少重复踩坑。
Discovering Multiagent Learning Algorithms with Large Language Models
Authors: Zun Li, Marc Lanctot
Affiliation: Unknown
使用 LLM 驱动的 AlphaEvolve 在多智能体强化学习算法空间中自动搜索，替代过去依赖人工迭代改进基线的流程。论文在不完全信息博弈和多智能体学习范式中发现新的算法变体，展示 evolutionary coding agent 可用于探索 MARL 设计空间并产生竞争性方法。
Evaluating AGENTS.md: Are Repository-Level Context Files Helpful for Coding Agents?
Authors: Thibaud Gloaguen, Martin Vechev
Affiliation: Unknown
系统评估 AGENTS.md 等仓库级上下文文件是否真的提升 coding agent 表现。论文从真实任务完成率和 agent 行为两个角度测试人工或自动生成的上下文，指出这类文件虽被广泛推荐，但收益依赖内容质量、任务类型和 agent 对上下文的实际使用方式。
Learning Personalized Agents from Human Feedback
Authors: Kaiqu Liang, Saghar Hosseini
Affiliation: Unknown
提出 Personalized Agents from Human Feedback，让 agent 通过持续人类反馈学习个体用户随时间变化的偏好。相比依赖静态交互历史或外部 profile，PAHF 支持冷启动与偏好漂移，在交互中更新个性化策略，使 agent 更贴近具体用户的长期需求。
Doc-to-LoRA: Learning to Instantly Internalize Contexts
Authors: Rujikorn Charakorn, Robert Tjarko Lange
Affiliation: Unknown
针对长上下文推理成本高和逐 prompt 蒸馏太慢的问题，提出 Doc-to-LoRA。方法训练轻量 hypernetwork，把输入文档即时转成 LoRA 参数，让模型把上下文信息快速内化到可插拔参数中，从而在保留上下文知识的同时减少长序列注意力开销。
AgentConductor: Topology Evolution for Multi-Agent Competition-Level Code Generation
Authors: Siyu Wang, Xinping Guan
Affiliation: Unknown
提出 AgentConductor，用拓扑演化优化多 agent 竞赛级代码生成。它根据任务难度调整通信图密度，并在迭代中进化协作结构，避免固定 workflow 无法适配不同问题。实验表明，动态拓扑能更好利用多 agent 协作推理，提升复杂代码题解质量。
ActionEngine: From Reactive to Programmatic GUI Agents via State Machine Memory
Authors: Hongbin Zhong, Suman Nath
Affiliation: Unknown
ActionEngine 将 GUI agent 从逐步截图-推理-点击的反应式执行转为带状态机记忆的程序化规划。系统复用已访问页面和操作模式，减少每一步都调用 VLM 的成本与延迟，并在复杂 GUI 任务中提升效率和准确率，适合重复流程较多的界面自动化。
Balancing Faithfulness and Performance in Reasoning via Multi-Listener Soft Execution
Authors: Nithin Sivakumaran, Elias Stengel-Eskin
Affiliation: Unknown
论文关注 CoT 解释的忠实性与任务性能之间的冲突，提出 REMUL 多监听者软执行框架。多个 listener 对推理链进行解释和反馈，通过多方强化学习提升推理过程对真实计算的反映程度，同时尽量避免单纯追求可解释性导致性能下降。
Learning to Rewrite Tool Descriptions for Reliable LLM-Agent Tool Use
Authors: Ruocheng Guo, Kamalika Das
Affiliation: Unknown
论文指出工具使用 agent 的瓶颈常在工具描述质量，而不只是模型或提示。作者学习自动重写面向人类开发者的模糊 tool descriptions，使其更适合 LLM 解析、选择和调用；在候选工具变多时，该方法能提升工具选择可靠性并减少接口歧义。
Helios: Real Real-Time Long Video Generation Model
Authors: Shenghai Yuan, Li Yuan
Affiliation: Unknown
Helios 是 14B 长视频生成模型，目标是在单张 H100 上达到约 19.5 FPS 的实时生成并支持分钟级视频。论文强调在不依赖常见抗漂移启发式和标准加速技巧的情况下保持长时序稳定，兼顾实时速度、长视频一致性和接近强基线的画质。
Heterogeneous Agent Collaborative Reinforcement Learning
Authors: Zhixia Zhang, Yikun Ban
Affiliation: Unknown
提出 HACRL，把异构 agent 的验证 rollout 在训练阶段共享，以提高多 agent on-policy 优化效率，同时保持推理时各 agent 独立执行。相比传统 LLM 多智能体 RL，HACRL 关注不同能力 agent 之间的协作训练，使各自从他人的成功经验中受益。
SWE-rebench V2: Language-Agnostic SWE Task Collection at Scale
Authors: Ibragim Badertdinov, Alexander Golubev
Affiliation: Unknown
SWE-rebench V2 面向软件工程 agent 的强化学习训练瓶颈，构建大规模、语言无关的 SWE 任务集合，强调可复现执行环境和可靠测试套件。它扩展现有 benchmark 在规模、语言生态和任务多样性上的不足，为训练而非仅评测 coding agent 提供数据基础。
UniG2U-Bench: Do Unified Models Advance Multimodal Understanding?
Authors: Zimo Wen, Yifei Shen
Affiliation: Unknown
UniG2U-Bench 系统评估统一多模态模型的生成能力是否真正促进理解能力。基准将 generation-to-understanding 分成 7 类机制和 30 个子任务，覆盖隐式或显式视觉生成辅助理解的场景，用于辨析统一模型在哪些任务上因生成能力获得理解收益。
T2S-Bench & Structure-of-Thought: Benchmarking and Prompting Comprehensive Text-to-Structure Reasoning
Authors: Qinsi Wang, Yiran Chen
Affiliation: Unknown
提出 T2S-Bench 评测文本到结构推理能力，并提出 Structure-of-Thought 提示，让模型先构造关键点、关系和结构化中间表示，再回答复杂阅读任务。实验显示显式结构化思考能在多类文本处理任务中稳定提升表现，尤其适合需要组织信息的长文本理解。
MOOSE-Star: Unlocking Tractable Training for Scientific Discovery by Breaking the Complexity Barrier
Authors: Zonglin Yang, Lidong Bing
Affiliation: Unknown
MOOSE-Star 针对科学发现中直接建模假设生成过程的组合复杂度问题。论文指出从海量知识中检索并组合灵感会导致不可承受的复杂度，并提出打破该复杂度屏障的训练思路，使模型能更可行地学习从背景知识生成科学假设。
Speculative Speculative Decoding
Authors: Tanishq Kumar, Avner May
Affiliation: Unknown
在标准 speculative decoding 中，草稿生成和目标模型验证仍有顺序依赖。论文提出 speculative speculative decoding，进一步并行化 speculation 与 verification 流程，以减少自回归解码瓶颈。该方法从解码算法层面提高推理吞吐，补充现有 draft model 加速路线。
Pretrained Vision-Language-Action Models are Surprisingly Resistant to Forgetting in Continual Learning
Authors: Huihan Liu, Yuke Zhu
Affiliation: Unknown
论文研究预训练 VLA 模型在持续学习中的灾难性遗忘问题，发现与从零训练的小型行为克隆策略不同，大规模预训练 VLA 对新技能增量学习出乎意料地抗遗忘。该发现提示预训练表征可能为机器人策略持续学习提供更稳定基础。

SWE-Explore: Benchmarking How Coding Agents Explore Repositories
Authors: Shaoqiu Zhang, Xiaodong Gu
Affiliation: 1, Shanghai Jiao Tong University 2 Xinjiang University, 3, University of Illinois at Urbana-Champaign 4 Independent Researcher, 5, The Chinese University of Hong Kong, § https://github.com/Qiushao-E/SWE-Explore-Bench
提出 SWE-Explore，用于单独评估 coding agent 在仓库探索阶段的能力。基准要求在固定行数预算内返回与 issue 相关的代码区域排序列表，覆盖 203 个开源仓库、10 种语言和 848 个 issue，并用成功修复轨迹提炼行级真值。实验表明覆盖率、排序和上下文效率与后续修复表现强相关，现代 agentic explorer 明显优于传统检索，但行级覆盖和高效排序仍是主要瓶颈。
On the Geometry of On-Policy Distillation
Authors: Zhennan Shen, Yi R. Fung
Affiliation: 1 HKUST, 5, 2 UT Austin, USTC, 6, 3 Zhejiang University, BUPT, 7, Nankai University
研究 on-policy distillation 在大语言模型推理训练中的参数更新几何。作者用多种参数空间诊断比较 OPD、SFT 与 RLVR，发现 OPD 更新更少权重、避开主方向，并快速锁定到低维子空间；限制训练在早期形成的更新子空间内仍能保持 OPD 性能，却会显著损害 SFT。结果说明 OPD 不是 SFT 与 RLVR 的简单中间形态，而有自身独特的更新几何。
Kwai Keye-VL-2.0 Technical Report
Authors: Kwai Keye Team, Ruilin Zhang
Affiliation: Kuaishou Group
提出开源 MoE 多模态模型 Keye-VL-2.0-30B-A3B，面向小时级长视频和代理任务。核心是将 DSA 适配到 GQA 多模态架构，实现 256K 上下文，并用多教师 on-policy 蒸馏与 Context/Video-RL 缓解多任务对齐遗忘，在长视频理解、时序定位和代理能力上取得同规模强性能。
ABot-Earth 0.5: Generative 3D Earth Model
Authors: Ming Qian, Hang Zhang
Affiliation: AMAP CV Lab
提出 ABot-Earth 0.5，用原生 3D Gaussian Splatting 表示从卫星影像生成连续大规模 3D 地球场景。系统可在每平方公里 10 分钟内合成可交互场景，并结合多级 LOD 支持 Web 地图渲染，为数字孪生、UAV 导航和具身智能仿真降低重建成本。
Latent Spatial Memory for Video World Models
Authors: Weijie Wang, Bohan Zhuang
Affiliation: Zhejiang University
提出 Mirage 的 latent spatial memory，将场景信息直接缓存在扩散模型 latent 空间，而不是 RGB 点云。方法通过深度引导反投影构建 3D latent cache，并用 latent warping 查询新视角，避免重复渲染和 VAE 编码，端到端生成最高快 10.57 倍、显存占用降低 55 倍。
FlashMemory-DeepSeek-V4: Lightning Index Ultra-Long Context via Lookahead Sparse Attention
Authors: Yan Wang, Dong Yu
Affiliation: Independent Researchers
提出 Lookahead Sparse Attention，用神经 Memory Indexer 预测后续解码真正需要的历史 KV chunks，只把关键块保留在 GPU。索引器可作为独立双编码器训练，无需加载大模型骨干；在 LongBench-v2、LongMemEval 和 RULER 上将平均物理 KV cache 压到 13.5%，精度基本保持并略有提升。
Self-Harness: Harnesses That Improve Themselves
Authors: Hangfan Zhang, Shuyue Hu
Affiliation: Shanghai Artificial Intelligence Laboratory
提出 Self-Harness，让 LLM agent 在无需人工或更强外部 agent 的情况下改进自身运行 harness。方法从失败执行轨迹中挖掘模型特定弱点，生成小而针对性的 harness 修改，并用回归测试筛选。Terminal-Bench-2.0 上三类模型均获得稳定提升，说明 harness 可由 agent 自身迭代适配。
EvoArena: Tracking Memory Evolution for Robust LLM Agents in Dynamic Environments
Authors: Jundong Xu, Zhiyuan Hu
Affiliation: National University of Singapore
提出 EvoArena，用连续版本更新刻画终端、软件和社交偏好等动态环境，评估代理能否识别变化并避免沿用过期行为；同时提出 git-like 的 EvoMem 记忆补丁历史，记录更新前后、理由与证据。实验显示现有代理在动态任务中表现脆弱，EvoMem 在 EvoArena、GAIA、LoCoMo 与链式任务上带来稳定提升。
MiniMax Sparse Attention
Authors: Xunhao Lai, Pengyu Zhao
Affiliation: MiniMax, Peking University
提出 MiniMax Sparse Attention，一种面向超长上下文的分块稀疏注意力。方法用轻量 Index Branch 为每个 GQA 组选择 top-k KV 块，主分支只做精确块稀疏注意力，并配套 GPU kernel。在 109B 多模态模型上基本保持 GQA 效果，同时在 1M 上下文显著降低注意力计算并加速推理。
From AGI to ASI
Authors: Tim Genewein, Shane Legg
Affiliation: Google DeepMind
讨论人类级 AGI 之后通向 ASI 的可能技术路径，并用 Universal AI 提供形式化参照。报告梳理扩展 AGI、范式转换、递归改进和大规模多智能体集体四条路径，分析各自可能遭遇的计算、算法、数据、社会与协调瓶颈，强调 ASI 进展高度不确定且需要跨学科研究准备。
